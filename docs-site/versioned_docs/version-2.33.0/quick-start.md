# Quick Start

1. **Download** the desktop app for your platform
2. **Launch** Muorg and add your music folders
3. **Browse** your library with the album grid or track table
4. **Edit** metadata by clicking a track and opening the metadata editor
5. **Sync** across devices by running muorg-server on your NAS

See [Desktop](/docs/desktop/), [Server](/docs/server/), or [Web Client](/docs/web-client/) docs for more details.
