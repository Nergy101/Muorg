# Desktop App

The Muorg desktop client is built with **Tauri 2 + Vue 3** and runs on macOS, Windows, and Linux.

## Key Features

- **Library view** — Table with album art, title, artist, album, year, duration, and path. Full-text search; group by album or artist; multi-select for bulk actions.
- **Album view** — Browse your collection as an album grid with cover art. Click an album to see its tracks.
- **Metadata editor** — Edit all major tags, embed album art, bulk-edit multiple tracks, auto-tag from MusicBrainz.
- **Playlists** — Create, rename, delete, reorder, and export to M3U. Smart playlists with dynamic rules.
- **Reports** — Find tracks with missing metadata, duplicates, or missing album art.
- **Playback** — Play/pause, previous, next, seek, volume, mute, shuffle. Maximized player view with large album art.
