# Android App

The Muorg Android client (Kotlin + Jetpack Compose) connects to a muorg-server for playback and library management.

## Features

- Browse library by album grid or track list
- Search and filter
- Stream music from your Muorg server
- Edit track metadata
- Sleep timer
- Offline playlist sync
- Home screen widget (Now Playing)
- Chromecast support
